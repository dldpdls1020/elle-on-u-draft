# 엘르온유 홈페이지 초안

대표 검토용 홈페이지 초안입니다.

## 반영 사항

- 오렌지·블랙·크림 디자인과 이탤릭 영문 디테일
- 사용자 제공 AI 히어로 영상: 무음 자동 재생·반복·모바일 인라인·재생 컨트롤
- 헤어스트록 눈썹 150,000원 이벤트 강조
- 속눈썹펌 40,000원(리뷰 작성 시), 눈썹 재방문 100,000원(1년 이내)
- 네이버 예약과 카카오 상담 버튼, 모바일 하단 고정 예약바
- 실제 시술 사례·원장 소개·상담 과정·FAQ·매장 사진
- 운영시간 09:30–17:00, 매주 일요일 휴무

## 확인이 필요한 사항

이벤트 기간, 잔흔 적용 조건, 리터치 조건, 리뷰 상세 조건, 상세 주소는 최종 확인이 필요합니다. 확정되지 않은 사항은 임의로 표시하지 않았습니다.

## 파일 안내

`index.html`: 홈페이지 / `styles.css`: 디자인 / `app.js`: 사진 확대 및 영상 동작 / `assets/`: 사용 이미지와 영상

`index.html`을 열어 미리 볼 수 있습니다. GitHub Pages를 사용하는 경우 저장소 Settings → Pages에서 main 브랜치의 /(root)를 선택합니다.

사진·영상은 홈페이지 검토를 위해 제공된 자료입니다. 별도의 재사용 허가를 부여하지 않습니다.
